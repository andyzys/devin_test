# 电商详情页 - 后续优化建议

## 后续迭代模块清单

以下模块作为后续迭代需求池，不纳入本期强实现：

| 模块 | 描述 | 目标指标 |
|------|------|----------|
| 真实晒单 | 用户真实晒单内容聚合展示 | 转化率提升 |
| KOL种草 | KOL/达人推荐内容嵌入 | 停留时长 +15% |
| 商品对比 | 同类商品参数对比功能 | 加购率提升 |
| 买家秀视频 | 用户上传的使用视频展示 | 社交信任感 |
| 使用场景 | 不同场景下商品使用展示 | 跳失率降低 |
| 品牌故事 | 品牌背景与理念展示 | 品牌认知度 |
| 直播入口 | 在线直播间入口嵌入 | 实时互动转化 |

## 转化优化方向

### 本期已落地

- **首屏突出利益点**：Banner 区叠加核心卖点标签
- **价格刺激强化**：售价突出、原价划线、折扣标签、倒计时
- **CTA按钮突出**：底部固定操作栏，主色统一、按钮圆角突出

### 后续优化项

| 优化方向 | 具体措施 | 预期效果 |
|----------|----------|----------|
| 社交信任感 | 展示购买人数、好友已购 | 降低决策成本 |
| 决策成本降低 | 商品对比、一键问答 | 减少用户犹豫 |
| 紧迫感营造 | 库存预警、限时标签 | 促进即时转化 |
| 个性化推荐 | 基于浏览历史的智能推荐 | 提升连带率 |

## KPI 目标（来自 PRD）
